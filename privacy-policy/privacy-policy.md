## File processing

The tools are designed to process selected files and entered content in volatile memory in the user's browser. File contents are not uploaded to an OpenStackTools file-processing server. Processing may still depend on the browser, device, extensions, network, and third-party libraries loaded by the page. The user should not use an environment they do not trust for confidential material.

## Data processed to operate the site

The static hosting provider may process connection and security information, such as IP address, requested resource, timestamp, and browser or network headers, to deliver and protect the site. Frontend assets are also requested from third-party CDNs, including Tailwind CSS and pdf-lib on the PDF tool; those providers may receive connection metadata. The operator does not control these providers' independent logs or retention practices.

The browser stores interface language and advertising consent preferences in `localStorage`. The consent record contains a policy version, timestamp, choice, and purpose. These values stay in that browser unless cleared and are not sent to the operator by the application.
